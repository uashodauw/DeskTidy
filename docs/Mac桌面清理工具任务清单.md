# Mac 桌面清理工具 任务清单（第一版）

> 基于《需求文档（第一版）》和《技术方案》中的方案一（原生 Mac 应用：Swift + SwiftUI）。

## 怎么使用这份清单

- **按编号顺序做**。每个任务标了"依赖"，依赖的任务没做完，就不要开始它。
- **一次对话只做一个任务**。可以直接对 AI 说："做任务清单里的任务 7"，并把需求文档里的"原则"和技术方案里的"容易踩的坑"一起发给它。
- **每个任务做完，按"验收"一步步亲自操作**。全部通过后，再用 git 存一次档（提交），然后进入下一个任务。
- 验收中用到的测试应用都是 Mac 自带的：**备忘录、计算器、文本编辑、Safari**。
- "面板"指点击菜单栏图标后弹出的小窗口。

## 阶段三：核心清理

### 任务 5：列出正在运行的应用

- **依赖：** 4
- **要做的事：** 在面板里显示当前正在运行的应用列表（图标 + 名字），不包括本应用自己。内部用应用的"身份证号"（Bundle ID）区分应用。
- **验收：**
  1. 打开计算器，再打开面板，列表里有"计算器"。
  2. 退出计算器，再打开面板，列表里"计算器"消失了。
  3. 列表里**没有**本应用自己。

### 任务 6：记住"当前正在用的应用"

- **依赖：** 5
- **要做的事：** 实时记住用户最后使用的那个应用（**不能**是本应用自己），显示在面板顶部："当前在用：××"。对应技术方案里的坑 1。
- **验收：**
  1. 打开 Safari，点进 Safari 窗口，然后点菜单栏图标。
  2. 面板顶部显示"当前在用：Safari"，**而不是**本应用的名字。
  3. 点进备忘录，再打开面板，显示变成"当前在用：备忘录"。

### 任务 7：一键清理（最简版）

- **依赖：** 6
- **要做的事：** 点"一键清理"后，除了"当前在用"的应用，把其他应用全部**隐藏**（不关闭）。暂时不管场景。
- **验收：**
  1. 打开备忘录、计算器、Safari，最后点进 Safari。
  2. 打开面板，点"一键清理"。
  3. 屏幕上只剩 Safari 的窗口。
  4. Dock 里备忘录和计算器图标下方的**小圆点还在**（说明只是隐藏，没有被关闭）。
  5. 点 Dock 里的备忘录图标，备忘录窗口原样出现，内容没丢。

### 任务 8：清理记录 + 一键恢复

- **依赖：** 7
- **要做的事：** 每次清理时，记下"哪些应用是本应用亲手隐藏的"。点"一键恢复"时，只把这些应用显示回来。对应技术方案里的坑 3。
- **验收：**
  1. 打开备忘录、计算器、Safari。
  2. 点进计算器，按 `⌘H` **手动**把计算器隐藏。
  3. 点进 Safari，打开面板，点"一键清理"：备忘录被隐藏。
  4. 点"一键恢复"：**备忘录回来了，计算器仍然是隐藏的**。
  5. 还没清理过的时候，"一键恢复"按钮是灰色的、点不了。

### 任务 9：快速找回

- **依赖：** 8
- **要做的事：** 面板里显示"已收起的应用"列表（只列本应用隐藏、且现在仍然隐藏的）。点击某一个，它就出现在最前面。
- **验收：**
  1. 打开备忘录、计算器、Safari，在 Safari 里执行一键清理。
  2. 面板的"已收起"列表里有备忘录和计算器。
  3. 点列表里的"备忘录"：备忘录窗口出现在最前面。
  4. 再打开面板，"已收起"列表里只剩计算器。

  3. 点"退出"，再在终端执行 `swift run DeskTidy` 重新运行。
  4. 打开面板，当前场景仍然是"开会"。

### 任务 11：清理时遵守场景名单

- **依赖：** 7、10
- **要做的事：** 一键清理时，"当前在用的应用"和"当前场景里的应用"都保留，其他的隐藏。
- **验收：**
  1. 场景选"AI 工作"。打开 Safari、计算器、备忘录，最后点进备忘录。
  2. 一键清理：**备忘录和 Safari 都保留**，计算器被隐藏。
  3. 场景切到"开会"，点进备忘录，再一键清理：这次 Safari 也被隐藏了，只剩备忘录。

### 任务 12：编辑场景里的应用

- **依赖：** 5、11
- **要做的事：** 面板里可以给当前场景添加或移除应用（从正在运行的应用中勾选）；改动自动保存。

  2. 点进 Safari，一键清理：**计算器没有被隐藏**。
  3. 退出本应用，重新运行，打开编辑场景："计算器"仍然是勾选状态。
  4. 取消勾选计算器，再清理：计算器被隐藏。

## 阶段七：减负建议

### 任务 16：记录每个应用的最后使用时间

- **依赖：** 5
- **要做的事：** 每当用户切换到某个应用，就记下时间，并**存到硬盘上**。在"正在运行的应用"列表里，每个应用旁边显示"上次使用：×分钟前"。对应技术方案里的坑 4。
- **验收：**
  1. 点进计算器，然后点进 Safari。
  2. 打开面板，计算器旁边显示"上次使用：刚刚"或"1 分钟前"。
  3. 等 3 分钟再看，显示约"3 分钟前"。
  4. 退出本应用并重新运行，计算器旁边的时间**没有被清零**。

### 任务 17：找出"很久没用"的应用

- **依赖：** 11、16
- **要做的事：** 面板设置里加"多久没用算很久"：1 分钟（测试用）/ 30 分钟 / 1 小时 / 2 小时，默认 1 小时。清理时找出超过这个时间没用、且不在当前场景、也不是当前在用的应用。
- **验收：**
  1. 把"多久没用算很久"设为 1 分钟。场景选"AI 工作"。
  2. 打开计算器，然后点进 Safari，等 1 分钟以上。
  3. 一键清理：出现"这些应用很久没用了"的列表，里面有**计算器**。
  4. 列表里**没有** Safari（它在场景里，也是当前在用的应用）。
  5. 把设置改回 1 小时，再清理：列表不出现。

### 任务 18：确认后礼貌退出

- **依赖：** 17
- **要做的事：** "很久没用"的列表里每个应用前有勾选框，**默认不勾选**；用户勾选后点"退出所选应用"，才请它们退出。只用普通退出，**永远不用强制退出**。对应技术方案里的坑 5。
- **验收：**
  1. 打开文本编辑，随便输入几个字，**不要保存**。
  2. 按任务 17 的方法让文本编辑出现在"很久没用"列表里。
  3. 不勾选任何应用，点"退出所选应用"（或直接关掉列表）：没有任何应用被退出。
  4. 勾选文本编辑，点"退出所选应用"：文本编辑**弹出"是否保存"的询问**，而不是直接消失。
  5. 在询问里点"取消"：文本编辑保持打开，输入的字还在。

### 任务 20：完整走一遍

- **依赖：** 1–19 全部完成
- **要做的事：** 不写新功能，只按下面的流程完整体验一遍，发现问题就记下来，单独开新任务修。
- **验收：**
  1. 打开 Safari、备忘录、计算器、文本编辑，场景选"AI 工作"，点进备忘录。

### 任务 20.1：装成本机应用，关掉终端也能用（任务 20 中发现的问题）

- **问题：** 用 `swift run DeskTidy` 启动时，关掉终端窗口，DeskTidy 也跟着退出。
- **依赖：** 19
- **要做的事：** 加一个打包脚本，把 DeskTidy 打包成 `DeskTidy.app` 装进"应用程序"文件夹（只给自己电脑用，不签名、不公证）；第一次以应用方式启动时，自动搬来之前的设置。
- **验收：**
  1. 运行 `./scripts/build-app.sh`：菜单栏出现 DeskTidy 图标。
  2. 关掉终端窗口：图标还在，一键清理正常工作。
  3. 之前设置的场景勾选、提示音开关、快捷键都还在。
  4. 退出 DeskTidy 后，在聚焦搜索里搜"DeskTidy"能重新打开。

### 任务 20.2：再点一次场景按钮，回到无场景模式（任务 20 中提出的改进）

- **依赖：** 20.1
- **要做的事：** 场景改成一排按钮；点已选中的场景，取消选中，进入无场景模式。无场景时，清理只保留当前在用的应用；"正在运行"列表不显示勾选框；这个状态重启后还在。
- **验收：**
  1. 点已选中的"AI 工作"：按钮变回普通样式，场景标题提示"未选"，列表里的勾选框消失。
  2. 打开 Safari、备忘录、计算器，点进备忘录后清理：只剩备忘录，Safari 也被收起。
  3. 退出并重新打开：仍然是无场景模式。
  4. 再点"AI 工作"：重新选中，之前勾选的应用还勾着。

### 任务 20.3：灰色按钮，操作更跟手（任务 20 中提出的改进）

- **依赖：** 20.2
- **要做的事：** 场景按钮、一键清理、一键恢复改成灰色样式：平时浅灰，按下或选中时深灰，不用蓝色；减少卡顿：面板不做淡入淡出，收起/恢复应用放到后台做，应用图标缓存，切换场景时面板高度不跳动。
- **验收：**
  1. 选中的场景按钮是深灰色，没有蓝色。
  2. 按住"一键清理"不放：变深灰；松手：恢复浅灰，并执行清理。
  3. 点"一键清理"后，面板立刻消失，提示浮窗和提示音马上出来，不需要等应用全部收起。
  4. 在三个场景和无场景之间来回点：按钮立刻变色，面板高度不跳动。

### 任务 20.4：面板变短；"很久没用"不要每次都弹（任务 20 中提出的改进）

- **依赖：** 20.3
- **要做的事：** "已收起""正在运行""设置"改成可折叠的行，默认收起，一次只展开一个，展开后列表最多显示 6 行；设置里加"很久没用的提醒"：每天最多一次（默认）/ 每小时最多一次 / 每次启动只提醒一次 / 每次清理都提醒（测试用），上次提醒的时间重启后也算数。
- **验收：**
  1. 打开面板：只看到当前在用、场景、一键清理、一键恢复，以及"正在运行""设置"两行（清理后还有"已收起"）。
  2. 点"正在运行"展开列表；再点"设置"：列表收起，设置展开。
  3. 提醒设为"每天最多一次"，多久没用设为 1 分钟：第一次清理弹出"很久没用"窗口，之后再清理不再弹出；重启后清理也不弹出。
  4. 提醒改为"每次清理都提醒"：每次清理都弹出。

### 任务 20.5：透明玻璃质感界面（任务 20 中提出的改进）

- **依赖：** 20.4；改之前的版本存档为 git 标签 `v0.1.0-before-glass`
- **要做的事：** 按钮、提示浮窗、"很久没用"窗口改成透明玻璃质感：macOS 26 及以上用系统的 Liquid Glass，更老的系统退回毛玻璃；选中/按下时仍为深灰色玻璃；文字保持清晰，操作不变卡。
- **验收：**
  1. 场景按钮、一键清理、一键恢复都是胶囊形玻璃按钮；选中的场景、按住的按钮是深灰色玻璃，白字清楚。
  2. 清理后的提示浮窗是玻璃胶囊，文字清楚。

  2. 按住下面明暗条的圆钮左右拖，亮度连续变，窗口不跟着跑。
  3. 按住圆盘和滑杆以外的空白处，仍然可以拖动整个设置窗口。

### 任务 23.6：按住圆盘或明暗条时不再拖动窗口（用户提出的改进）

- **依赖：** 23.5
- **原因：** 23.5 之后，按住左键拖动仍然会把整个设置窗口拖走。
- **问题在哪：** 两处叠在一起。
  1. 接鼠标的那一层没有把自己的尺寸撑开，点在圆盘上实际点到的是窗口空白，空白处本来就会拖动窗口。
  2. 就算点到了，窗口也是先收到按下、先决定拖窗口，轮不到圆盘。位置在 `SettingsWindow.sendEvent` 和 `HoldDragView`。
- **要做的事：** 鼠标层铺满圆盘和明暗条。窗口一收到按下，先看看是不是点在这两处；是的话自己跟手直到松开，这次不拖窗口。点在旁边空白处仍然拖窗口。
- **验收：**
  1. 按住圆盘拖：圆点跟着走，窗口不动，颜色连续变。
  2. 按住明暗条拖：亮度连续变，窗口不动。
  3. 按住旁边空白处：窗口跟着走。
